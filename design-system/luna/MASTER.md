# Lunarca Design System

> 本文是 Lunarca 当前界面语言的索引；可运行的 Token 事实源为 `packages/styles/src/tokens/` 目录（`@lunarca/styles`，桌面与网页共用；物理归属与层叠顺序见 TDD-15 §3.3），功能交互契约归各 PRD/TDD。页面规则不得复制或覆盖它们。

## 品牌

- 名称：**Lunarca**。
- 图标：深色圆角方形中的下弦月；暖象牙色亮面与石墨灰暗面清晰分离，所有陨石坑均为圆形并完整落在所属明暗面内。
- 感知：安静、始终环绕、随时可唤起的个人 AI 气场；图形在 20px Dock/托盘尺寸仍能一眼识别为月亮。
- 禁止：渐变、描边、椭圆陨石坑、将撞击坑跨越明暗交界，或用表情符号代替图标。

## 信息与交互

Lunarca 的统一闭环是 **捕获 → 处理 → 审阅 → 落地 → 继续**：

1. 捕获入口始终可见，并说明真正的快捷键、权限或模型前置条件。
2. 处理阶段显示真实阶段与可恢复的失败原因，不伪造完成状态。
3. 审阅先呈现可编辑结果，原始内容和最终内容的关系可理解、可回退。
4. 落地由 Rust 写入 Markdown Vault；页面给出结果去向并可重新打开。
5. 继续操作与最近产物相邻，用户无需在不同页面间猜测下一步。

主窗口遵循“工作台而非仪表盘拼盘”：左侧为任务与知识导航，中间为当前工作，右侧只在上下文需要时显示检查器；HUD 保持非激活面板，动作最小化，不能抢走前台应用焦点。

## 组件原则

- 主按钮只表达当前闭环的下一步；危险操作使用错误状态色并要求明确语义。
- 状态使用 `TaskStatus` 和语义状态 Token，禁止用颜色单独传递含义。
- 键盘焦点、悬停、禁用与 reduce-motion 都是组件契约，不以布局位移制造反馈。
- 响应式尺寸、圆角、间距、阴影、动效均引用已定义 Token；采用 CSS logical properties。
