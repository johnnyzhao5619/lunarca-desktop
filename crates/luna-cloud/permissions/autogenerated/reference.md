## Default Permission

Lunarca 云客户端：账户与登录、设备管理、账户数据导出与注销、权益、用量与月度上限、收单与签名模型目录。

#### This default permission set includes the following:

- `allow-account-state`
- `allow-account-sign-in-begin`
- `allow-account-sign-in-password`
- `allow-account-sign-in-code`
- `allow-account-sign-in-set-password`
- `allow-account-sign-in-request-code`
- `allow-account-change-password`
- `allow-account-sign-in-browser`
- `allow-account-sign-in-reopen-browser`
- `allow-account-sign-in-cancel`
- `allow-account-sign-in-resolve-device-limit`
- `allow-account-sign-out`
- `allow-devices-list`
- `allow-device-revoke`
- `allow-account-web-access`
- `allow-account-set-web-access`
- `allow-account-web-sessions`
- `allow-account-revoke-web-session`
- `allow-account-revoke-all-web-sessions`
- `allow-account-deletion-preview`
- `allow-account-delete`
- `allow-account-export`
- `allow-entitlements`
- `allow-usage`
- `allow-spend-cap-set`
- `allow-billing-offer`
- `allow-billing-available`
- `allow-billing-checkout`
- `allow-billing-portal`
- `allow-billing-verify-card`
- `allow-catalog-status`
- `allow-prompt-catalog-status`
- `allow-trust-status`
- `allow-trust-confirm-change`
