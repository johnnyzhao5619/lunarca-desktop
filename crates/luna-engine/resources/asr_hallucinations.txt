# ASR 幻觉短语词表（事实源，数据驱动；勿散落硬编码到代码）。
#
# Whisper 在静音 / 低能量 / 背景音段会「脑补」训练集里的字幕尾注、水印、
# 频道口号——这些内容**从未在音频中出现**（如用户实测的「字幕by索兰娅」）。
# 纯数值阈值（no_speech / logprob / entropy）挡不住它们，须显式短语过滤。
#
# 语法：
#   - 以 `#` 起始的行为注释。
#   - 以 `~` 起始的行为**标记（substring）**：段文本包含该标记即判为幻觉，
#     用于「字幕by<任意人名>」这类无限变体（高精度、近零误伤）。
#   - 其余为**整段（exact）**：段文本规范化后与之相等才判为幻觉。
#
# 匹配前双方都做规范化（小写化、去标点、折叠空白）；故 `amara.org` 写原样即可。
# 事实源引用：TDD-03 §2.3（幻觉抑制为一等参数）。

# ── 标记：视频/直播尾注口号（substring；简繁 + 观看/收看 变体，真机流式实测）──────
# whisper 在低能量/静音（含短窗补零段）会脑补主播签退语；简繁与「观看/收看」「下集/下次」
# 均出现且常与他句拼成同一段（如「謝謝大家收看 下次再見」）——用 substring 覆盖组合与独立
# 变体。这些是广播签退语，会议/口述场景近零误伤（区别于裸「谢谢」，故只匹含「观看/收看」全句）。
