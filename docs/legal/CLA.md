# Lunarca 个人贡献者许可协议（Individual CLA）——草案

> 状态：🔴 **草案·未生效·待法务复核**（TDD-12 §7、ADR-029）。
> 形式对标 Apache ICLA：贡献者**保留版权**，授予项目方再许可权——**不是版权转让**。
> 生效方式（规划）：经 cla-assistant 或同类机器人在 Pull Request 上电子签署；
> 机制上线前本仓库不合并外部代码贡献（见 [CONTRIBUTING.md](../../CONTRIBUTING.md)）。
> 企业雇员批量贡献所需的企业版 CLA（CCLA）在首个企业贡献者出现时另行制定。

感谢你有意向 Lunarca 项目（版权人：Weijia Zhao，下称「项目方」）提交贡献。
为厘清知识产权授权关系，请在提交贡献前阅读并同意以下条款。

## 1. 定义

- **「你」**：签署本协议的个人版权人。
- **「贡献」**：你有意提交给项目方、纳入 Lunarca 项目的任何原创作品
  （代码、文档、设计、翻译等），包括对既有作品的修改与补充。
  「提交」指任何形式的送交行为（Pull Request、补丁、issue 附带的代码等），
  但你书面显著标注「非贡献（Not a Contribution）」的除外。

## 2. 版权许可授予

你保留你对贡献的版权与其他一切权利。你授予项目方及项目方的再许可受让人一份
**永久、全球、非独占、免费、免版税、不可撤销**的版权许可，允许其：
复制、衍生、公开展示、公开执行、**再许可**（包括以任何其他许可条款再发行，
**包括商业与专有许可条款**）以及分发你的贡献及其衍生作品。

> 注：这条「可再许可」是本协议的核心——它使项目得以同时维持
> AGPL v3 开源版与闭源商业版（双许可，[LICENSE_FAQ.md](../../LICENSE_FAQ.md)）。
> 同时项目方公开承诺：你的贡献**始终**同时保留在 AGPL v3 版本中——
> 「本地是开源版的全部」的边界承诺见 LICENSE_FAQ.md。

## 3. 专利许可授予

你授予项目方及项目方的再许可受让人、以及贡献所并入作品的接收者一份
**永久、全球、非独占、免费、免版税、不可撤销**（本节所述情形除外）的专利许可：
就你的贡献单独构成侵权、或你的贡献与其所提交时所针对的作品结合构成侵权的
你可许可的专利权利要求而言，允许制造、委托制造、使用、许诺销售、销售、
进口及以其他方式转移贡献及所并入的作品。
若任何实体对你或任何其他实体提起专利诉讼，主张你的贡献或其所并入的作品
构成直接或帮助性专利侵权，则本协议下授予该实体的专利许可自诉讼提起之日终止。

## 4. 你的声明

- 你在法律上有权授予上述许可。若你的雇主对你创作的作品享有权利，
  你声明已获得雇主为该贡献签发的许可，或雇主已放弃对该贡献的权利。
- 每项贡献均为你的原创作品。若贡献中包含任何第三方作品，
  你须在提交时完整标注其来源与许可条款，由项目方按
  许可证核查纪律（ADR-005、TDD-04）裁决是否纳入。
- 你无义务提供技术支持，贡献按「现状（AS IS）」提供，
  不附带任何明示或默示的担保。
- 如你日后知悉任何使上述声明不实的事实，你同意及时通知项目方。

## 5. 其他

- 本协议不改变你依 AGPL v3 使用 Lunarca 的任何权利。
- 本协议适用法律与争议管辖在法务复核时确定。
